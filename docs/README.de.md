Testberichte erhalten die am jeweiligen Datum festgehaltenen Ergebnisse, Grenzen und Artefaktkennungen. Eine
Übersetzung ist kein neuer Testlauf. Lokale Artefaktpfade sind Nachweisreferenzen, keine mitgelieferten Anhänge.
Historische Verweise auf ABNAHME.md/TODO.md bleiben als Text erhalten, wenn die Dateien im Checkout fehlen.

Die [Drittanbieterhinweise](../THIRD_PARTY_NOTICES.md) enthalten englische Originallizenztexte und werden nicht übersetzt.
`npm run check:docs` prüft vollständige Sprachpaare, Links, Abschnitte, Beispiele und Werkzeugreferenzen.
